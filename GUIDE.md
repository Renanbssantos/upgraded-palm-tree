# Phase 2 — Modern Angular and reactivity

Plan: `docs/training-plan.md` → Phase 2. This branch is the end of the phase (same files as `phase2-step09`).

## Run it

```bash
cd catalog
npm install
ng serve
ng test --watch=false
```
